# Skeg web

Explainer site for the [Skeg](https://github.com/Cincinnatus101010/skeg) data-fetching library, built with
[`@iantroisi/ui`](https://www.npmjs.com/package/@iantroisi/ui).

Live: [https://cincinnatus101010.github.io/skegweb/](https://cincinnatus101010.github.io/skegweb/)

```bash
npm install
npm run dev
```

Opens on [http://localhost:5173](http://localhost:5173).
